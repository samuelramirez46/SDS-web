# SDS — Sistema de Cifrado y Descifrado

Esta versión web adapta el programa de escritorio proporcionado, conservando los cuatro algoritmos originales, el alfabeto español con Ñ, las pantallas informativas, el menú de métodos y la sección que muestra el código fuente original.

## Archivos
- `app.py`: aplicación web Streamlit.
- `requirements.txt`: dependencia necesaria.
- `codigo_fuente_sds.py`: código original completo de escritorio, mostrado en la sección «Código utilizado».

## Publicar en Streamlit Community Cloud
1. Sube estos tres archivos al repositorio público `SDS-web` de GitHub.
2. En Streamlit Community Cloud, crea una aplicación.
3. Selecciona el repositorio `samuelramirez46/SDS-web`, rama `main` y archivo principal `app.py`.
4. Pulsa Deploy.

## Ejecutar localmente
`pip install -r requirements.txt`
`streamlit run app.py`
